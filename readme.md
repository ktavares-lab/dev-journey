## Instruções para Executar o Portfólio

1. Clone o repositório:
   ```bash
   git clone https://github.com/ktavares-lab/dev-journey.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd dev-journey
   ```

3. Abra o arquivo `index.html` em seu navegador de preferência.

## Resumo das Funcionalidades

- **Home:** Apresentação inicial com nome e área de atuação.
- **Sobre mim:** Informações sobre o perfil e trajetória do desenvolvedor.
- **Minha jornada:** Timeline interativa com evolução acadêmica e técnica.
- **Conhecimentos e competências:** Exibição de tecnologias e ferramentas dominadas.
- **Projetos e Filtros:** Listagem de projetos com opções de filtragem por categoria (Java, Python, Dados).
- **Experiências e Interesses:** Seções destacando vivências acadêmicas, hobbies e viagens.
- **Contato:** Links diretos para GitHub, LinkedIn e e-mail.
- **Navegação e Responsividade:** Menu fixo/mobile adaptado para computadores, tablets e celulares.
